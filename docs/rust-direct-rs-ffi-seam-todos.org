** TODO Fix trisection axis selection (synthesis P1-2, highest leverage)
Rust splits the MINIMUM-depth axis (~rs:81-88~); C++ splits the largest
DENORMALIZED side ([[file:src/domain/direct_optimizer.cpp][direct_optimizer.cpp:247-250,329-331]]). They coincide
only for isotropic ranges — Tier-3 fails at the first anisotropic
trisection. Either re-anchor the Rust split or prove JTML stage ranges
are always isotropic (they aren't: trunk ranges are set per-axis in
settings).

** TODO Resolve box-id interleaving tie-break divergence
Rust assigns ALL center ids during trisect before any A/B ids
(~rs:168-190~): order = oc1..ocN, A1,B1,A2,B2... C++ inserts oc,A,B
interleaved per POH box ([[file:src/domain/direct_optimizer.cpp][direct_optimizer.cpp:337,367-383]]) and takes the
oldest-inserted column minimum on ties. On cross-parent equal-cost ties
within one size column the two sides select different boxes -> divergent
POH sets next iteration. Structural finding, not yet demonstrated by a
failing run — either re-order Rust's id assignment to interleave, or
write the failing-case test proving it unreachable.
