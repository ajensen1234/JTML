\section{Tutoring Homework List}
\label{sec:org7a49ecb}
\textbf{\textbf{How to use:}} Work top-down. Tier 1 is contract/interface — do next session. Tier 2 is quality/hardening — do soon. Tier 3 is advisory — pick when touched.
\subsection{Tier 1 — Should do next session (contract / interface)}
\label{sec:org34ebbe3}

\subsubsection{1. Remove \texttt{println!} timing — \texttt{obs-tracing-over-log}, \texttt{obs-library-facade}}
\label{sec:org2949345}
Delete the \texttt{println!("\{:?\} per iteration")} block. Library crates emit via \texttt{tracing}, never install a subscriber. Fold stats into \texttt{RunOutcome} (\texttt{avg\_per\_call\_us}, \texttt{it\_per\_sec}) or gate behind \texttt{\#[cfg(debug\_assertions)]}.
\subsubsection{2. Replace \texttt{INFINITY} sentinel — \texttt{type-option-nullable}, \texttt{api-must-use}}
\label{sec:orgca70dd3}
Return \texttt{Result<RunOutcome,NoFiniteIncumbent>} or \texttt{best\_cost: Option<f64>}. Add \texttt{\#[must\_use]} on \texttt{run()}. Sentinels are indistinguishable from real +∞.
\subsubsection{3. Add \texttt{From<[f64;6]> for Pose} — \texttt{conv-from-not-into}, \texttt{type-newtype-ids}}
\label{sec:orgdaa08b8}
\texttt{impl From<[f64;6]> for Pose} (+ inverse). Two hand-rolled index blocks → two one-liners, never transpose an axis.
\subsubsection{4. Batch the FFI bridge — wall-clock knob}
\label{sec:org25c47d4}
Per-pose \texttt{UniquePtr<Point6D>} + one \texttt{cxx} call per pose defeats batch GPU eval. Add \texttt{evaluate\_batch(\&CppCost, \&[f64], \&mut [f64])} seam; keep per-pose fallback for tests.
\subsubsection{5. Fix budget overshoot}
\label{sec:org46445b7}
Guard fires before \texttt{2*|POH|} batch. Cap with \texttt{remaining = budget.saturating\_sub(calls)} and \texttt{min(|POH|, ceil(remaining/2))} then re-enable the property test.
\subsection{Tier 2 — Worth doing soon (quality / hardening)}
\label{sec:orgb5f4667}

\subsubsection{6. Rename Direction variants — \texttt{name-types-camel}, allow\textsubscript{attributes} ban}
\label{sec:org51028b9}
\texttt{\#[allow(non\_camel\_case\_types)]} violates your own \texttt{allow\_attributes\_without\_reason = "warn"}. Rename to \texttt{X,Y,Z,Xa,Ya,Za} or \texttt{Axis::X}, drop the attribute.
\subsubsection{7. Use integer exponents and cache size — \texttt{opt-inline-small}}
\label{sec:org2035f24}
\texttt{powf → powi(-(2*d as i32))} (integer exponents) + consider caching size on box. Preserve bit-exact term ordering (\texttt{size\_is\_bit\_identical\_under\_depth\_permutation} test).
\subsubsection{8. Reuse Vec buffers — \texttt{mem-with-capacity}, \texttt{mem-reuse-collections}}
\label{sec:org8a29744}
\texttt{Vec::with\_capacity} + reusable scratch buffers as optimizer fields for allocation-free inner loop.
\subsubsection{9. Document public API — \texttt{doc-all-public}, \texttt{doc-errors-section}}
\label{sec:org4e9e4ad}
No \texttt{///} on public items. Document determinism + budget contract, \texttt{POHSettings} variants, whether discriminants =0/=1 are FFI-stable.
\subsubsection{10. Pin MSRV — \texttt{proj-msrv-declare}}
\label{sec:orgd43efbf}
No \texttt{rust-version}. Pin \texttt{rust-version = "1.85"} (2024 edition floor).
\subsubsection{11. Tune release profile — \texttt{perf-release-profile}, \texttt{opt-lto-release}, \texttt{opt-codegen-units}}
\label{sec:org795e710}
No \texttt{[profile.release]}. For \texttt{staticlib} into Qt/CUDA: \texttt{lto}``thin'' codegen-units=1= is free wall-clock.
\subsubsection{12. Add criterion bench — \texttt{test-criterion-bench}, \texttt{perf-black-box-bench}}

\subsection{Tier 3 — Advisory / food-for-thought}
\label{sec:orgc31ecae}

\label{sec:orgf221901}

\subsubsection{14. Float-order fragility in \texttt{size()}}
\label{sec:orgf81327e}

\subsubsection{15. Non-finite boxes silently vanish}
\label{sec:orge213c58}

\label{sec:org2906026}
